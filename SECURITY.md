# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not open a public
GitHub issue for a security problem.

Email the maintainer directly at **david.bickford@gmail.com** with:

- a description of the issue and its impact,
- steps to reproduce (a minimal example helps), and
- any suggested fix, if you have one.

GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(the **Report a vulnerability** button under the repository's *Security* tab) is
also welcome if you prefer it.

## Supported versions

redcache is pre-1.0 and solo-maintained. Only the latest `v0.x` release receives
security fixes. There are no backports to earlier `v0.x` tags.

| Version        | Supported |
|----------------|-----------|
| latest `v0.x`  | yes       |
| older `v0.x`   | no        |

## Response expectations

This is a personal, single-maintainer project, not a funded product. I'll make a
best effort to acknowledge a report within about a week and to address confirmed,
serious issues promptly, but I can't commit to a formal SLA. Please allow
reasonable time for a fix before any public disclosure.
